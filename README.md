## 1. 什么是“合理”访问？

在网络受限的环境下，“合理”访问包含三个维度：

1.  **无感体验 (Split Tunneling)**：访问国内 App（微信、抖音、支付宝）走直连，访问海外 App（Ins、推特）走代理。互不干扰，无需频繁开关软件。
2.  **身份隔离 (Privacy)**：防止国内 App 读取你的海外上网指纹，同时防止海外平台检测到你的真实物理位置。
3.  **持续稳定 (Stability)**：不会因为 IP 频繁变动而导致社媒账号触发风控验证。

## 2. 核心痛点：为什么你的账号总被封？

很多用户注册 Twitter 或 Facebook 时，倒在了第一步（秒封）。这通常不是因为你的手机号有问题，而是因为**你的网络环境“太脏了”**。

各大社媒平台（尤其是 X/Twitter 和 Facebook）拥有极强的风控系统，它们会检测以下特征：

* **万人骑 IP (Abused IP)**：你使用的机场节点是几千人共用的廉价节点，前一个人可能用来发了垃圾广告，你的账号因此被“连坐”。
* **数据中心 IP (Data Center IP)**：你使用的是云服务器（AWS/Azure）机房 IP，而不是当地居民的家庭宽带 IP。平台会判定你为“机器人”。
* **IP 跳变 (IP Hopping)**：这一秒在香港，下一秒在日本。这种物理距离的瞬间移动会直接触发安全锁。

## 3. 防封号策略：原生 IP 与节点选择

要想一劳永逸地解决封号和加载慢的问题，必须在节点选择上下功夫。

### ✅ 黄金标准：原生 IP (Native IP) / 住宅 IP (ISP)
在选择机场或节点服务商时，请务必寻找带有以下标签的线路：
* **`[原生]`** / **`[Native]`**
* **`[家宽]`** / **`[ISP]`** / **`[住宅]`**

**原理解析**：这类 IP 在数据库中注册为当地运营商（如美国的 AT&T，新加坡的 Singtel），Facebook 和 Twitter 会认为你是一个**真实的当地用户**，从而给予最高的信任度。

### ❌ 避坑指南
* **避免使用免费 VPN**：免费的往往是最贵的（出卖隐私），且 IP 质量极差。
* **慎用香港节点注册**：虽然香港速度快，但由于政策原因，Ins 和 TikTok 对香港 IP 有特殊限制，建议日常使用**美国、新加坡、台湾或日本**节点。

## 4. 全平台客户端配置指南

有了好节点，还需要好工具（客户端）来承载。推荐使用支持 **Rule（规则模式）** 的软件。

| 平台 | 推荐软件 | 关键设置 (必看) |
| :--- | :--- | :--- |
| **iOS** | **Shadowrocket** (小火箭) | 全局路由选 **`配置`** (Config)；在配置中开启“自动更新”以获取最新分流规则。 |
| **Android** | **Clash Meta** / Surfboard | 运行模式选 **`规则模式`** (Rule)；建议开启“DNS 劫持”防止 DNS 泄露。 |
| **Windows** | **Clash Verge (Rev)** | 打开 `System Proxy` (系统代理)；选择 `Rule` 模式。 |
| **Mac** | **Clash Verge** / Surge | 同 Windows，Surge 体验更好但价格昂贵。 |

> **💡 技巧**：开启规则模式后，软件可以 24 小时挂在后台。访问百度/淘宝时流量不走代理，访问 Ins 时自动加速，这才是真正的“合理”上网。

## 5. 各平台特别注意事项 (Ins/Twitter/FB)

### 📸 Instagram (Ins)
* **痛点**：图片/Story 加载不出来。
* **对策**：Ins 是重图应用，对**带宽**要求高。选择机场节点时，优先看“倍率”低的节点（流量充裕），尽量选 **新加坡** 或 **日本** 节点（物理距离近，延迟低）。

### 🐦 Twitter (X)
* **痛点**：账号冻结、无法私信 (+86限制)。
* **对策**：Twitter 对 IP 稳定性要求极高。
    * 注册时：务必使用 **美国原生 IP** + **全局模式** + **Chrome 无痕浏览**。
    * 使用时：不要频繁更换节点地区。

### 📘 Facebook (FB)
* **痛点**：注册秒封、需要上传照片验证。
* **对策**：FB 是“实名制”社交的代表。
    * **养号**：新号注册后，前 3 天不要大量加好友，保持在同一个 IP 地址下活跃。
    * **Cookie**：尽量不要在浏览器频繁登入登出。
